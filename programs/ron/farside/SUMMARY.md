# FARSIDE (v0.1.0 — the whole Moon as a turning globe)

**STATUS: HW-VALIDATED — flashed by Ron 2026-11-14: "it looks good".** (v0.1.0
as built; no RTL sim was ever run. Presets are still hand-typed placeholders.)
LUNA's sibling (Ron, 2026-11-14: "do the spinning globe version"). LUNA shows
the Earth-facing side at full detail; FARSIDE wraps the whole Moon on a
sphere that turns, so the far side comes round. Softer than LUNA: about 10
screen pixels per map cell at the default size, against LUNA's 6.

## What it draws

A globe of the Moon from NASA's LRO maps, turning about its vertical axis,
lit by a sun that swings round it (new -> full), with crater shadows along
the terminator, earthshine, an optional halo, and the live picture as the
sky or as the globe's own surface.

| | |
|---|---|
| K1 Size | disc radius, 12% .. 107% of screen height (default 37.5% = 3/4-height disc) |
| K2 / K3 Position | centre X / Y |
| K4 Relief | crater shadow depth at the terminator, plus a light emboss everywhere |
| K5 Turn | which face is toward you; one full turn across the knob (0 = near side) |
| K6 Spin | centre = still; either way, 4.5 min .. 1 s per turn |
| S7 Sky | Black / Video |
| S8 Surface | Moon / Video (the live picture lit as the globe's face; flat, not wrapped) |
| S9 Lit Side | Right / Left |
| S10 Earthshine | Faint / Bright |
| S11 Halo | Off / On |
| P12 PHASE | new moon -> full moon |

Differences from LUNA's panel: no Tone, no Orbit (Turn and Spin take those
knobs).

## How it works

Everything LUNA does (see `../luna/SUMMARY.md`): accumulator geometry in
disc radii, second-order t = xn^2 + yn^2, sqrt ROM for z, vblank sequencer
with a serial divider and multiplier, parity sub-banked bilinear, clean avid,
latency 8, virtual 1080-line coordinates. What is new:

- **Map layout for an upright globe (28 of 32 EBR):** albedo 256 x 80 x 4 bit
  (20), east-west slope 128 x 32 x 4 bit (4), sqrt ROM 1024 x 8 (2), asin ROM
  512 x 11 (2). Rows are sin(latitude), which is simply the screen line.
  Columns are longitude, which wraps, so turning the globe is one add.
- **Longitude per pixel:** asin(q), q = xn / (row radius). q is one more
  accumulator (26-bit, wraps; only its value inside the disc matters).
- **Per-line job in the horizontal blanking:** the row radius changes every
  line, so each line computes 1 / radius: integer sqrt of w = 1 - yn^2 (13
  clocks), divide 2^24 / root (25), then q's start and step on the serial
  multiplier (2 x 25). About 90 clocks from the line tick; the tick is 8
  clocks after the generated avid ends. SD NTSC has 138 clocks of blanking.
- **Pole rows** of the albedo are held (clamped), the slope map fades to zero
  there, so its wrap is harmless.
- Pipeline is 3 stages longer than LUNA's (asin address, ROM, fabric), so the
  accumulators run 6 pixels ahead; the first 6 pixels of a line repeat.

## Files

81.1 / HD Dual 79.0 MHz, SD Analog 76.8 / SD HDMI 82.7 / SD Dual 84.8 MHz;
6352-6364 / 7680 LC (83%), 28 / 32 EBR.

79.0 / 81.6 MHz; router2 seed 1 = 70.5 MHz (FAIL). Use router1.

## Not verified

- No GHDL render (build-first rule). The integer model matches the float
  mock-up look; nothing has compared the RTL against the model.
- **A GHDL image sim cannot run this program faithfully:** the tester's fake
  horizontal blanking is 64 clocks and the per-line job needs about 100, so
  in sim every line would use a stale radius. Hardware has 138+ clocks.
- Sky = Video and Surface = Video are untested anywhere.
- Limb shimmer while turning: the map is squeezed hard at the edge of the
  disc and there is no mip-mapping. Only hardware will show whether it is
  visible.

## Resolution notes

- The first 6 pixels at the left screen edge repeat pixel 6. Only visible if
  the globe overlaps the left edge.
- The limb is softened over 2-4 pixels at 1080-line rasters and 1-2 pixels at
  720p / SD.
- SD (480i / 576i) has the least blanking for the per-line job: 138 / 144
  clocks against about 100 needed. It fits, with the smallest margin of any
  mode.
- Faint streaks converge on the poles (every column of the map meets there).
