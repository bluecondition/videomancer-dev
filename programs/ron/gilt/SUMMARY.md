## Architecture (short)

- Coarse map: 2^bs-px blocks (64 HD / 32 SD) holding mean luma, detail and mean chroma.
  One rotating line per block row is sampled each field and IIR-smoothed, in two
  ping-pong EBR banks.
- Cells: hashed-height bands × hashed-width tiles (per-band phase) × one hashed KD
  split. A 17-clock engine precomputes each tile's geometry, zone (ornament / gold
  paint / meadow) and colour class one tile ahead of the beam.
- Pixel path: leaf → centred offsets → octagonal radius / Chebyshev / 16-sector angle
  → motif compares → palette index → palette ROM (bank × LEAF × 64: v0.10's gold/brown
  ramp + v2's colours, generated by tools/gen_pkg.py) → grain, flecks, relief, aura → flesh or video alternative →
  blanking gate.
- Hardware contracts: U/V swapped at the input latch and the output compose; generated
  avid; EBR delay line for the original video; hsync-locked beam x (voted origin); per-
  field parameter latch; serration-safe field event; frame-line coordinates under
  interlace.
