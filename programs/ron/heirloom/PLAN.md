## Implementation checklist (for every program)

1. Files: `programs/ron/heirloom/<name>/<name>.vhd`, `<name>.toml`, `SUMMARY.md` (photo breakdown, design table, controls table, status). Architecture name = program name; entity `program_top`; `program_id = "com.czartroniks.<name>"`, author czartroniks, `program_type = "processing"`, version 0.1.0, `description` ≤ 127 bytes, `categories` from the 37-entry list, preset names ≤ 15 chars, labelled knobs use `initial_value_label` and no numeric fields.
2. Copy the skeleton of escalator / cocoon / starburst v0.2.0: timing-ID steps (`f_vstep_x/y`), vblank zone (no avid 1024 clocks) with `s_zgo` per-field latch, width measured from source avid (`s_w`), virtual 1080-line geometry, serial multiplier/divider in the zone, generated avid (`p_gavid` + `g_start`, beam counters initialised on the `g_start` edge), per-line values computed at the source avid fall and committed at its rise, line buffer 2048×32 (no `no_rw_check` where read/write can collide), palette ROMs as `signal pal : t_pal := f_pal` read in a clocked process (EBR), a second fabric register after every EBR output, output conditioning (chroma 9-tap box pair + luma [1 2 1] + luma to ~777) then the blanking gate on `s_gav_sr(C_LAT-3)`, `C_LAT` a multiple of 4 = `processing_delay_clks`. Colours in the hardware convention (u = Cr, v = Cb); the verified table: red (328,960,360) orange (584,772,212) yellow (840,584,64) green (580,136,216) blue (164,440,960) cyan (678,64,663) magenta (426,887,808) violet (349,756,852) indigo (192,608,696) pink (752,612,512) lavender (747,516,594) white (940,512,512) black (64,512,512).
3. Source switch: `S<n> Source = Video / Osc` (default Video); the oscillator block (`s_ox/s_oy/s_ot`, `f_tri8`) muxed at the line-buffer write (or wherever the video enters) so every video-path control stays live.
4. All 12 controls live at every P12 position; P12 = the headline with a designed 100 %; knobs with a zero that kills a feature get a floor; bipolar knobs get a ±8 deadband; P12 glided (1/8 of the gap per field).
5. VHDL traps seen today: no slice of a function result (`shift_right(v,2)(9 downto 0)` → variable first); `unsigned & literal` is ambiguous inside `signed(...)` when array-of-unsigned types exist → use `shift_left(resize(...))`; `resize(x, N) & '0'` is N+1 bits (width mismatches surface only in `ghdl --synth`); `to_unsigned(1024, 10)` truncates; cast 8-bit unsigned gains to signed via `resize(.., 9)`; sums of 12-bit signed clamp in 13 bits.
