# HELIOS (v0.1.0 — the Sun as a turning, boiling globe)

**STATUS: timing-closed only — built 2026-11-14, NOT flashed, no RTL sim.**
Fourth of the globe family. The geometry engine is FARSIDE's (HW-validated);
the intensity / boil / heat-ramp path is new. Only the heat ramp was checked
numerically; there is no full-frame model of this one.

## What it draws

A self-luminous globe: a brightness map (bright network, eight active regions
with sunspots) turning about the vertical axis, modulated by a boil, darkened
toward the limb, coloured by a heat ramp, with a corona.

| | |
|---|---|
| K1 Size | disc radius, 12% .. 107% of screen height |
| K2 / K3 Position | centre X / Y |
| K4 Boil | how strongly the boil modulates the surface (0 = the plain map) |
| K5 Turn | which face is toward you |
| K6 Spin | centre = still; right = features move left to right |
| S7 Sky | Black / Video |
| S8 Look | White Light / Fire |
| S9 Surface | Sun / Video (the live picture's brightness as the surface) |
| S10 Limb | Dark / Flat |
| S11 Corona | Off / On |
| P12 ACTIVITY | calm and dim -> flaring (brightness, boil speed, corona) |

## How it works (what is new over FARSIDE)

- **Memory (28 of 32 EBR):** surface 256 x 64 x 4 bit (16), one 128 x 32 x
  4 bit tiling noise map stored TWICE (8), sqrt ROM (2), asin ROM (2).
- **The boil** is the product of two reads of the same noise map: the second
  copy is mirrored (it takes the opposite sign of asin), and each drifts
  across and down at its own rate (faster with Activity).
- **Intensity:** I = map x gain, gain = 40 + Activity + (boil - 15) x Boil / 4
  (64 = x 1), then x limb factor. The edge cover is folded into the limb
  factor, so the last pixel or two fade through red.
- **Heat ramp** without multipliers: R, G, B are clamped straight lines of I
  (two sets of slopes / thresholds for the two looks), then Y / Cr / Cb by
  shift-adds in the hardware convention. Checked numerically:
  `.moon_work/model_out/_sun_ramp.png`.
- 64 map rows, so the row coordinate is the disc coordinate itself (no x 1.25).
- Corona = FARSIDE's halo, x 2 in luma, tinted orange, brightness from Activity.

## Build

`NEXTPNR_ROUTER="--router router1" ./build_programs.sh ron helios`

v0.1.0, 2026-11-14, router1: HD Analog 81.3 / HD HDMI 81.5 MHz (seed 1),
**HD Dual 78.7 MHz on seed 2** (seed 1 missed), SD Analog 87.1 / SD HDMI 84.9
/ SD Dual 87.0 MHz (seed 1); 6177-6201 / 7680 LC (81%), 28 / 32 EBR.

**Build seeds:** HD Dual = seed 2 (router1). All others seed 1.

## Not verified / known limits

- No GHDL render, no full-frame model: the boil's scale, speed and contrast
  were chosen from the float mock-up (`.moon_work/sun.py`) and will want
  tuning on hardware.
- The corona is a smooth glow; the mock-up's streaky corona (noise in screen
  space) is not built.
- "Pumpkin segment" streaks converge on the poles, more visibly than on the
  Moon, because the noise layers share the longitude grid.
- Sky = Video and Surface = Video are untested.
