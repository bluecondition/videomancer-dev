# LUNA (v0.1.0 — the Moon as seen from Earth, lit as a sphere)

**STATUS: timing-closed only — built 2026-11-14, NOT flashed, no RTL sim.**
First of two planned Moon programs (Ron, 2026-11-14: a realtime, realistic 3D
Moon, disc at least 3/4 of the screen height; a simplified, soft Moon is
fine). The sibling is a spinning globe (far side included), mocked up only.

## What it draws

The near side of the Moon from NASA's LRO maps, on a disc of any size and
position, lit by a sun that swings round it (new -> full). A second map of
the surface's east-west slope tilts the lighting, so craters shadow the
terminator. Earthshine, an optional halo, a warm / cold tone, and the live
picture as the sky behind the Moon or as the Moon's own surface.

| | |
|---|---|
| K1 Size | disc radius, 12% .. 107% of screen height (default 37.5% = 3/4-height disc) |
| K2 / K3 Position | centre X / Y |
| K4 Relief | crater shadow depth at the terminator, plus a light emboss everywhere |
| K5 Tone | cold blue <- grey -> amber |
| K6 Orbit | 0 = still (phase = the slider); else the phase cycles, 4.5 min .. 1 s |
| S7 Sky | Black / Video |
| S8 Surface | Moon / Video (the live picture lit as the Moon's face) |
| S9 Lit Side | Right (waxing) / Left (waning) |
| S10 Earthshine | Faint / Bright |
| S11 Halo | Off / On |
| P12 PHASE | new moon -> full moon (cos of the sun angle is linear in the slider) |

## How it works

- **Memory (26 of 32 EBR):** albedo 128 x 128 x 4 bit (16), east-west slope
  128 x 64 x 4 bit (8), sqrt ROM 1024 x 8 (2). Each map is four sub-banks by
  (row parity, column parity): one read per bank = the 2 x 2 bilinear
  neighbourhood. No mux on the RAM data: the weight is flipped (16 - f) when
  the left / top texel is the odd one.
- **Geometry is all accumulators**, in disc-normalised units (xn, yn in
  radii), so Size only changes the steps: u (texels), m = xn sin(A), and
  t = xn^2 + yn^2 as a second-order DDA (t += d, d += dd per pixel; the row
  value T and its difference Dy step once per active line). t < 1 is the disc;
  z = sqrt(1 - t) from the ROM; mu = z cos(A) + m; relief subtracts
  slope x Relief; brightness = eased clamp(4 mu) x albedo.
- **Vblank sequencer:** one serial divider (1/R) and one 30 x 23 serial
  multiplier make the 12 products the accumulators start from. Started when
  no active video has been seen for 2048 clocks (never from vsync). sin(A)
  comes from the same sqrt ROM. Knobs K1/K2/K3/P12 glide (Q10.4, 1/16 per
  field).
- **Virtual 1080-line coordinates** from the timing ID: same picture at SD,
  720p and 1080p, round on 4:3 SD.
- **Clean avid** (aurora / cubist recipe), latency 8 in every mode. The
  accumulators run 3 pixels ahead, so live video is only 7 registers deep.
- Colour in the hardware convention (u carries Cr).

Traps met while writing it:
- A second-order DDA floors every step, so t at the disc centre went
  slightly negative and wrapped: a black dot at the exact centre. T starts
  at +2^-11.
- The per-line registers (T, Dy, v) were written by both the line tick and
  the sequencer: adder -> data mux -> second adder, 14.3 ns (64-69 MHz). Now
  each only clears to a constant (sync set/reset) or adds a registered
  increment: one carry chain.
- Sign flips (lit side) are applied where they are free: m and its step are
  stored one's-complemented, Relief is a signed multiplier operand.

## Files

- `luna.vhd`, `luna.toml`
- `luna_pkg.vhd` — the ROMs, generated by `make_pkg.py` (NOT a build hook: it
  reads the NASA maps from `.moon_work/src/`, `albedo.tif` =
  lroc_color_poles_4k.tif and `ldem_4.tif`, SVS "CGI Moon Kit", public domain)
- `.moon_work/model.py` — integer model of the RTL arithmetic (same widths
  and truncations); renders 1080p / 720p / 480p. Use it for a pixel diff if a
  GHDL render is ever needed.
- `.moon_work/mock.py`, `globe.py` — the float look mock-ups (both versions).

## Build

`NEXTPNR_ROUTER="--router router1" ./build_programs.sh ron luna`

v0.1.0, 2026-11-14, **router1, seed 1 on all six**: HD Analog 82.7 / HD HDMI
82.7 / HD Dual 82.7 MHz, SD Analog 81.2 / SD HDMI 77.6 / SD Dual 82.7 MHz;
5824-5841 / 7680 LC (76%), 26 / 32 EBR.

router2 (the builder default) is marginal on this netlist: HD Analog 72.2 /
71.0 / 80.9 MHz on seeds 1 / 2 / 3. Use router1.

(The first cut, before the accumulator restructure, was 6121 LC and missed
every HD config on router2: 63.8-68.6 MHz.)

## Not verified

- No GHDL render: per the build-first rule the first check is the hardware.
  The integer model matches the float mock-up look, but nothing has compared
  the RTL against the model.
- Sky = Video and Surface = Video are untested anywhere (the model is black
  sky only).

## Resolution notes

- The first 3 pixels at the left screen edge repeat pixel 3 (the lookahead).
  Only visible if the Moon overlaps the left edge.
- The limb is softened over 2-4 pixels at 1080-line rasters and 1-2 pixels
  at 720p / SD.
- At Size above ~60% the 128-texel map is visibly soft (17 px per texel at
  the top of the knob).
