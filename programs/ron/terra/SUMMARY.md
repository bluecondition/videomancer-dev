# TERRA (v0.1.0 — the Earth as a turning globe, in colour, with clouds)

**STATUS: timing-closed only — built 2026-11-14, NOT flashed, no RTL sim.**
Third of the globe family (LUNA, FARSIDE, TERRA, HELIOS). The geometry engine
is FARSIDE's, which Ron flashed and approved the same day; the colour and
cloud path is new and has only been checked in an integer model.

## What it draws

NASA's Blue Marble on a globe that turns about its vertical axis, in 16
colours, with a cloud layer drifting over it, day and night with a soft
terminator, a thin blue atmosphere round the limb, and the live picture as the
sky or as the globe's own surface (under the clouds).

| | |
|---|---|
| K1 Size | disc radius, 12% .. 107% of screen height |
| K2 / K3 Position | centre X / Y |
| K4 Clouds | clear sky .. normal (centre) .. overcast |
| K5 Turn | which face is toward you (0 = Africa / Atlantic side) |
| K6 Spin | centre = still; right = the Earth's own way (features move left to right) |
| S7 Sky | Black / Video |
| S8 Surface | Earth / Video |
| S9 Sun Side | Right / Left |
| S10 Night | Dark / Moonlit |
| S11 Atmosphere | Off / On |
| P12 DAYLIGHT | night side toward you -> full daylight |

## How it works (what is new over FARSIDE)

- **Memory (28 of 32 EBR):** surface 256 x 80 as a 4-bit palette index (20),
  cloud cover 128 x 32 x 4 bit in FARSIDE's slope-map slot (4), sqrt ROM (2),
  asin ROM (2).
- **Palette before bilinear:** the 16-colour palette (k-means on the map) is
  logic, one LUT per output bit, applied to each of the four taps; Y, U and V
  are then interpolated separately. No index blending.
- **Coarse weights:** Y and clouds use weights 0..8, chroma 0..4 (quarter
  texel steps are invisible at 4:2:2). All the lerps and small products are
  gated shift-adds (`f_mulw`), not `*`.
- **Clouds:** read at the surface column plus a drift that advances 3 / 65536
  of a turn per field (a turn in about 6 minutes). alpha = cover x Clouds; Y
  moves toward white, the chroma gain is light x (1 - alpha).
- **Chroma follows the light**, so the night side goes neutral.
- Terminator ramp is 5/8 mu (softer than the Moon's); the halo reaches only to
  1.22 radii and is tinted blue.

Size history (the lesson): the first cut used `*` for every lerp and gain and
was ~1650 cells over FARSIDE (would not fit). Coarse weights + gated
shift-adds brought it to +300. Then the cloud-blend stage (video select ->
subtract -> product -> add in one stage) ran at 15.5 ns; moving the surface
select one stage earlier took HD Analog from 59-65 MHz to 86-93 MHz.

## Files

- `terra.vhd`, `terra.toml`
- `terra_pkg.vhd` — generated by `make_pkg.py` (NOT a build hook). Surface:
  NASA SVS a002915 `bluemarble-2048.png` in `.moon_work/src_earth/`.

  `cloud_field()` for a real map when one is to hand.

## Not verified / known limits

- No GHDL render (and, as with FARSIDE, the image tester's 64-clock blanking
  cannot run the per-line job faithfully).
- Sky = Video and Surface = Video are untested.
- No city lights (no memory for a night-side map).
- Land is slightly posterised up close (16 flat colours, nearest index).
- The two darkest palette entries are nearly identical ocean blues (k-means
  weights by area); a de-duplicated palette would spend them better.
- Pole streaks, the 6-pixel repeat at the left screen edge, and SD having the
  least blanking margin are inherited from FARSIDE.
